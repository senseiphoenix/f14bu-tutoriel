FTI : imagerie
tactique

Le Fast Tactical Imaging System capture, met en file d'attente et transmet des images tactiques entre appareils — il remplace l'ancien enregistreur AVTR sur le B(U).

Aucun bouton HOTAS confirmé pour ce système sur le profil pilote de ce site : le FTI se pilote via un panneau cockpit dédié (souris/click-to-explain), pas via une commande bindable au manche ou à la manette. Cette fiche décrit donc le fonctionnement du système, pas une checklist de boutons HOTAS.

Alimentation et sources

Le commutateur principal a trois positions : OFF, STANDBY (moteur sous tension, bande prête) et ON (enregistrement vidéo continu). Quatre sources peuvent être sélectionnées pour l'enregistrement : le HUD, le TCS, le LANTIRN, et les écrans PTID.

Deux modes de capture

ModeComportement
SNAPCapture un instantané unique, une seule image.
BURSTCapture des images à intervalle prédéfini, pendant une durée prédéfinie — s'arrête automatiquement si la file d'attente se remplit (environ 188 images).

Chaque capture est ensuite traitée selon le mode retenu : capture/send (transmission immédiate) ou capture/hold (stockage dans une file d'attente avant décision).

Les trois files d'attente

FileRôle
Hold QueueImages capturées en attente de révision — c'est ici que tu parcours ce que tu viens de photographier avant de décider quoi en faire.
Send QueueImages marquées pour envoi — en mode capture/hold, quand aucun destinataire n'est sélectionné et qu'aucune réception n'est en cours, les images non compressées de la Hold Queue peuvent être compressées et déplacées ici.
Receive QueueImages reçues depuis un autre appareil (ailier, AWACS) — le pendant réception de la Send Queue.

Navigation dans la Hold Queue au PTID : VIEW → HOLD → NEXT/PREV. Une image intéressante se marque avec MARK pour la faire passer vers la Send Queue ; l'envoi effectif se lance avec SEND, qui transfère une image à la fois vers la carte image du destinataire, avec un indicateur de pourcentage de transfert.

Fichiers sur le disque

Les enregistrements se retrouvent sous Saved Games/DCS_F14/TIS/ (le sous-dossier exact peut varier selon ta version DCS/instance) : images au format .JPG, plus un journal d'événements horodatés. Utile pour un débriefing après-vol, en dehors du jeu.

À vérifier en jeuLe chemin exact du dossier de sauvegarde et les libellés précis des boutons du panneau physique n'ont pas pu être confirmés au-delà de ce que montre la vidéo source — vérifie via le click-to-explain avant de t'y fier pour une procédure critique.
